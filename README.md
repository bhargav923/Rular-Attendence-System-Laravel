## 📌 About

**Rural Attendance System** is a smart attendance management system designed for rural schools.

It uses **QR Code, Face Verification and ESP8266** to make student attendance faster, easier and more secure.

---

## ✨ Features

* 👨‍🎓 Student Management
* 🔳 QR Code Attendance
* 📷 Face Verification
* 📡 ESP8266 Integration
* 📊 Attendance Dashboard
* 📄 Attendance Reports
* 📥 Excel / PDF Export
* 🔐 Secure Authentication

---

## 🛠️ Technologies

* 🟥 Laravel
* 🐘 PHP
* 🍃 MongoDB
* 🌐 HTML / CSS / JavaScript
* 📡 ESP8266
* 🔳 QR Code

---

## 🔄 Attendance Flow

```text
👨‍🎓 Student
     ↓
🔳 QR Code Scan
     ↓
📋 Student Verification
     ↓
📷 Face Verification
     ↓
✅ Attendance Marked
     ↓
🍃 MongoDB
     ↓
📊 Attendance Report
```

---

## 🎯 Objective

To provide a **low-cost, smart and reliable attendance solution** for rural schools while reducing manual attendance work and proxy attendance.
